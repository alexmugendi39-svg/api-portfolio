# Kenyan Business Currency Tracker

A Python command-line tool that converts KES to USD, EUR, GBP, UGX, and TZS using live exchange rates.

Built for Kenyan businesses quoting international clients.

## Problem
A Kenyan business owner quoting a client abroad needs to know the current value of their price in USD, EUR, or GBP. Googling rates every time is slow and unreliable.

## Solution
This tool fetches live rates from ExchangeRate-API and instantly converts any KES amount.
